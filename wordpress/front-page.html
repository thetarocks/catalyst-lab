02 / EXPERIMENTS

Risk & networks

What a hedge or a risk measure can leave out.

STOCHASTIC SIMULATION

Discrete delta hedging ↗

Finance a short-call hedge across 600 stock paths. Examine rebalancing error, transaction costs and volatility misspecification.

Run experiment →Maths & code
What should I look for?

More frequent trading can reduce replication error while increasing fees. Pricing volatility and path volatility are separate assumptions.

LINEAR ALGEBRA & STATISTICS

Portfolio tail risk ↗

Hold mean and covariance fixed while changing the tail model. Compare diversification, a grid frontier and expected shortfall.

Run experiment →Maths & code
What should I look for?

The same mean and volatility can conceal different worst-case losses. Compare the loss quantile with expected shortfall.

GRAPHS & FIXED-POINT ALGORITHMS

Interbank contagion ↗

Solve eight connected balance sheets together. Trace secondary defaults across ring, complete and hub networks.

Run experiment →Maths & code
What should I look for?

A numerical clearing iteration is not a day in a bank run. Watch which institutions default only because another bank cannot pay.
